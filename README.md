## 这是什么

月光宝盒AI 是一个以「无限画布」为核心的 AI 智能体平台。你可以直接用自然语言告诉 AI 要做什么，也可以自己在画布上拖拽节点、连线组合，把提示词、模型、图像和视频处理串成完整的工作流。

### 核心能力

| 能力 | 说明 |
| --- | --- |
| 对话即创作 | 用文字描述需求，AI 智能体在画布上执行，改动可撤销/重做 |
| 无限画布 | 自由平移缩放，工作流规模不受限制，多卡片画布性能优化 |
| 节点式工作流 | 提示词、模型、后处理各自独立成节点，改一步只重跑一步 |
| 多模型调度 | 按类目选择模型，灵活切换，按需计费 |
| 图像与视频生成 | 文生图、图生图、图生视频逐步接入，一个画布串起创作管线 |
| 技能扩展 | 支持 Skills，可按需添加能力 |

### 三步上手

1. **添加节点** — 从节点库拖出提示词、模型、图像等模块
2. **连线组合** — 连成你要的处理流程，例如：提示词 → 文生图 → 放大 → 输出
3. **运行出图** — 结果直接显示在画布上，不满意就局部重跑
